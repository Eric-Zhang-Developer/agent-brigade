# Mission: jotter (toy example)

## Why
A teaching example for agent-brigade's project profile, not a real product. Someone wants to jot one-line notes
from the terminal and find them later.

## Who
One person, one machine.

## What
`python3 -m jotter add "text"`, `list`, and `search WORD`.

## Non-negotiables
- Never lose a note: writes only append.
- Search is case-insensitive substring match, newest first.

## Not doing
- Sync, accounts, a GUI.
