# Project budget

A side project has no prize money behind it. Spend has to fit a monthly number you chose on purpose.

1. Set `[budget].monthly_usd` in `kit.toml` (API spend plus any paid tiers). Subscriptions you'd pay anyway don't
   count, but their **usage limits** do: write them down.
2. Set a **hard limit** in every provider that allows one, and an alert at 50%. Alerts alone are not caps.
3. Route work by task type (`core/docs/budget.md`): strongest model for planning and review, cheaper models for
   mechanical work.
4. At 75% of the month's budget, agents take no new feature work (`core/docs/method.md` §8). Finish, fix and
   document instead.
5. Check spend in the weekly routine. Write a decision record if you raise the cap.
